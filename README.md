
# arena-connect-project
    Studio : GameForge Digital
    Mission : Concevoir et développer l’interface utilisateur d’une application web dédiée à la communauté E-sport.
    Nom du projet : Arena Connect
    Objectif : Créer un réseau social pour les joueurs et passionnés d’E-sport, avec une interface responsive, interactive et au design gamer.
## fonction principale
- Accueil – Présentation du concept Arena Connect.
- Connexion / Inscription – Accès et création de compte.
- Profil Joueur – Informations, avatar, niveau, jeux favoris.
- Paramètres – Modification du pseudo, mot de passe, préférences.
- Actualités – Liste d’articles E-sport (mise en page Grid).
